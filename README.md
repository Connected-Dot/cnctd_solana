# cnctd_solana

Solana blockchain integration with token operations and transaction building.

## Installation

```toml
[dependencies]
cnctd_solana = "0.1.11"
```

## Features

- Solana SDK re-exports
- Token program constants
- Associated token address utilities
- RPC client wrapper
